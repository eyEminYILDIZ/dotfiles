# Handy 

Handy is a voice dictation tool. It supports a lot of local models for offline speech recognition, making it a versatile choice for users who prefer not to rely on cloud services.

## Models

### Nemotron Streaming 3.5

Nemotron Streaming 3.5 is a local model optimized for real-time speech recognition. It provides high accuracy and low latency, making it suitable for live dictation scenarios.
It supports 28 languages, making it a versatile choice for multilingual users.
