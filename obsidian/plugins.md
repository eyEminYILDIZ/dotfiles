# Obsidian Plugins

## Claude Sidebar

The Claude Sidebar plugin integrates the Claude AI assistant directly into Obsidian, providing contextual assistance, note summarization, and intelligent suggestions within the sidebar.

## Git

The Git plugin integrates Git version control directly into Obsidian, allowing you to manage your notes' version history, commit changes, and synchronize with remote repositories without leaving the application.

## Iconize

The Iconize plugin allows you to add custom icons to your notes and folders in Obsidian, making it easier to visually organize and identify your content.

## Kanban

The Kanban plugin allows you to create and manage Kanban boards within Obsidian, helping you organize tasks and projects visually.

## Open Tab Settings

The Open Tab Settings plugin allows you to customize the behavior and appearance of tabs within Obsidian, providing options for managing open notes and improving navigation efficiency.

## Terminal

The Terminal plugin integrates a terminal emulator directly into Obsidian, allowing you to execute command-line operations without leaving the application.

## Vault Statistics

The Vault Statistics plugin provides detailed insights into your Obsidian vault, including note counts, word counts, and other metrics to help you understand and manage your knowledge base effectively.

## Vimrc Support

The Vimrc Support plugin enables Vim keybindings and configuration support within Obsidian, allowing users who are familiar with Vim to navigate and edit their notes efficiently using their existing Vim setup.
